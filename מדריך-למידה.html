🟦 הרצאה 01 — AI כווקטורים במרחב N-ממדי

נקודות ליבה

  • בינה מלאכותית (AI) = כל מכונה שיודעת להחליף פעולות של בני אדם (ולעיתים בעלי חיים).
  • למידת מכונה (Machine Learning) = ה"מוח" של ה-AI; היכולת ללמוד מנתונים קיימים (שיש) ולהסיק מסקנות על נתונים לא-ידועים (אין).
  • למידה עמוקה (Deep Learning) = תת-תחום המבוסס על רשת נוירונים מלאכותית, בהשראת נוירונים ביולוגיים במוח.

ארבעה תחומי ML (טבלה)

תחום תיאור דוגמה
רגרסיה (Regression) תחזית ערכים על בסיס נתונים קיימים חיזוי מחיר מניה
קלסיפיקציה (Classification) סיווג לקטגוריות מוגדרות זיהוי חתול/כלב, זיהוי ספרות
למידת חיזוקים (Reinforcement Learning) קבלת החלטות אדפטיבית תוך כדי תנועה ניהול רחפן, שחמט
גילוי אנומליות (Anomaly Detection) זיהוי חריגה ממצב נורמלי אבטחה, פרצות סייבר

הרעיון המרכזי — הכול וקטור

  • כל מידע (טקסט, תמונה, קול, משפט) ניתן לייצוג כסדרת מספרים = וקטור במרחב N-ממדי.
  • וקטור = סדרת מספרים; מימד הווקטור = כמות האיברים (פיצ'רים). כל וקטור = נקודה במרחב N-ממדי.
  • תמונה 1000×1000 פיקסלים → וקטור במיליון מימדים.
  • קרבה בין נקודות = דמיון משמעותי; ריחוק = שוני. זהו הבסיס לכל פעולות ה-AI.
  • "דוד הלך לטייל" → "משה הלך לטייל" (וקטור קרוב) מול "משה הלך לעולמו" (רחוק).

מושגי Data

מושג הגדרה
Data נתונים הנמדדים מהמציאות (גובה, משקל, לחץ דם)
תיוג (Label) הסיווג: 0 = לא מתאים, 1 = מתאים
Data Set שילוב Data + תיוג — תנאי הכרחי לאימון
פיצ'ר (Feature) תכונה בודדת נמדדת
סמפל (Sample) שורה בודדת ב-Data Set (דגימה אחת)

Overfitting (למידת-יתר)

מכונה (או סטודנט) שלמדה "בעל פה" את השאלות במקום להבין את החומר — תצליח רק בשאלות זהות, ותיכשל בתחזית אמיתית על נתונים חדשים.

אבטחת מידע

כל שאלה שנשלחת ל-LLM ענן "יוצאת החוצה" ועלולה להיחשף ל-man-in-the-middle. שימוש במחשבי צבא עלול להיחסם.

🟦 הרצאה 03 — טרמינל (CLI) והתקנת Codex

נקודות ליבה

  • טרמינל (Terminal) = הפעלת המחשב במקלדת בלבד — טקסט נכנס, טקסט יוצא. קיים מהיום הראשון של המחשוב, בכל מערכת הפעלה.
  • למה קריטי לסוכן? סוכן AI יודע רק לקרוא ולכתוב טקסט — לא להפעיל עכבר. הטרמינל הוא הגשר בין הסוכן למחשב.
  • CLI (Command Line Interpreter) = מודל שפה (LLM) שרץ מקומית בטרמינל (בניגוד לענן/דפדפן).

כלי CLI לפי חברה

חברה CLI
OpenAI (ChatGPT) Codex (הכלי בשיעור)
Anthropic (Claude) Claude Code
Google (Gemini) Gemini CLI

פקודות טרמינל בסיסיות

פעולה פקודה
ניווט לתיקייה cd <folder>
יצירת תיקייה mkdir <name>
הצגת תוכן dir
ניקוי מסך cls

  • פרויקט = תיקייה. שורש המערכת: C:\ ("אברהם אבינו" של התיקיות).
  • Windows: בקסלאש \ (לא סלאש / כמו לינוקס/מאק). פקודות Case Sensitive; זהירות ברווחים ומקפים.

4 תוכנות להתקנה (לפי סדר)

  1. PowerShell 7 (טרמינל מודרני, אייקון שחור)
  2. Notepad++ (עורך Plain Text — נקי, ידידותי לסוכן)
  3. Node.js ("תוכנה שמתקינה תוכנות") + npm (מנהל חבילות)
  4. Codex CLI: npm install -g @openai/codex
  5. (בשיעור הבא: Python 3.13)

מושגים חשובים

  • npm (Node Package Manager) — מתקין תוכנות מ-npmjs.com; מגיע עם Node.js.
  • אחרי התקנת Node.js — חובה לסגור ולפתוח את הטרמינל (אחרת node -v לא יזוהה).
  • Authentication / OAuth 2.0 — codex login פותח דפדפן, מאשרים, ו-Codex מקבל access token. מומלץ Google Sign-In.
  • Sandbox ("ארגז חול") — מצב הרצה מבודד עם הרשאות מצומצמות (בקורס: option 2).
  • Prompt Injection — ניצול זדוני; לכן Codex שואל "האם אתה סומך על התיקייה?".
  • /exit יוצא מ-Codex ונשאר בטרמינל; exit סוגר את הטרמינל.
  • תוכנה = ספר מתכונים; שפת תכנות = שפת המתכון. עובדים עם Python (לא לומדים לתכנת — הסוכן כותב).

⭐ הרצאה 04 — כלכלת ה-AI (ההרצאה הכי כבדת-מושגים!)

המרצה הדגיש: כל התוכן, כולל רשימת המקורות, הוא חומר מבחן. זהו "שיעור תיאורטי וניהולי רחב", לא כתיבת קוד.

מילות מפתח (13 מושגי-על)

כלכלת AI · חברת העלות השולית האפסית (Zero Marginal Cost Society) · ויכוח החישוב הסוציאליסטי · סוכני AI אוטונומיים (Agentic AI) · ספר הטכנולוגיה המשונן (Jagged Technological Frontier) · דחיסת פריון (Productivity Compression) · גישת המשימות (Task-Based Approach) · פיצול המשטר / הון סוכנים (Regime Fork) · ההשטחה הגדולה וטווח שליטה (Great Flattening & Span of Control) · כלכלת הקשב (Attention Economy) · מיסוי רובוטים אופטימלי (Optimal Robot Tax) · לאומנות טכנולוגית ומגן הסיליקון (Techno-Nationalism & Silicon Shield) · תלות גומלין נשקית (Weaponized Interdependence).

שתי הכלכלות הקלאסיות

ממד כלכלה סוציאליסטית כלכלה קפיטליסטית (שוק)
הקצאה תכנון מרכזי, חלוקה לפי צורך כוחות שוק, היצע וביקוש
תמחור מחירים קבועים ע"י פקידים מחירים דינמיים: P → MC
כשל היסטורי כשל אפיסטמי, שחיתות, אי-יעילות אי-שוויון ומונופוליזציה
  • ויכוח החישוב הסוציאליסטי: פון מיזס + היאק הוכיחו שללא שוק חופשי אין חישוב כלכלי רציונלי; המידע הכלכלי מקומי, סובייקטיבי ומבוזר ולא ניתן לריכוז (Hayek, 1945).

כניסת ה-AI

  • סוכן AI (Agentic AI) = ישות תוכנה אוטונומית המבצעת משימות מקצה-לקצה שדרשו מומחיות אנושית (חוזה שעלה ~$2500 → סנטים).
  • השפעה על עלות הייצור (3 סיבות): (1) זמינות 24/7; (2) Scalability — אינסוף סוכנים במקביל; (3) קצב למידה אקספוננציאלי.
  • מסקנה: בשוק תחרותי מבוסס-סוכנים, P → MC → 0 (העלות השולית האפסית של Rifkin).

כלכלת האינסוף (Post-Scarcity Economy)

  • כשעלות השעתוק שואפת לאפס, מוצרים הופכים ל"מוצר כמו אוויר" — זמין לכל, חינם (כמו שיחות סלולר בעבר).
  • ספר הטכנולוגיה המשונן (Jagged Frontier, Dell'Acqua/HBS/BCG): גבול יכולת ה-AI לא אחיד ולא ישר. משימות בתוך הגבול — שיפור מרשים; מחוץ לגבול — נפילות והזיות. לכן Human-in-the-Loop קריטי.

שבירת מעמדות הידע

  • הידע הסטטי (תארים, שנות ניסיון, ידע מקצועי סגור) מאבד מערכו כמקור כוח. הרופא/פרופ' עם 20 שנות ניסיון מול ילד בן 18 עם כלי AI.
  • דחיסת פריון (Productivity Compression, Noy & Zhang, Science): ChatGPT הפחית זמן משימה ב-40% ושיפר איכות ב-18%. עובדים חלשים יותר נהנים הכי הרבה — הפער מול המומחים כמעט נסגר.

רגולציה: מיסוי סוכנים (הפתרון המוצע)

  • הצעת סגל: מס על סוכני AI למימון תקופת המעבר (בהשראת מהפכת הלודיטים).
  • מגובה ב-Guerreiro, Rebelo & Teles (Review of Economic Studies): מיסוי רובוטים אופטימלי (מודל Mirrleesian) — מס למעבר בלבד, שואף לאפס בסיום. ביקורת נגד: ITIF (מסי רובוט פוגעים בחדשנות).

עיצוב ארגוני חדש — ההשטחה הגדולה

  • קריסת הפירמידה הקלאסית (מנכ"ל → מנהלי ביניים → עובדי ביצוע). בסיס הפירמידה (עובדים טכניים) מוחלף ראשון.
  • שני מודלים: טרפז שטוח (היררכיה אפסית) וטרפז הפוך (בסיס מבוצע ע"י סוכנים, נשארים מנהלים).
  • ההשטחה הגדולה (Deloitte, 2025): טווח שליטה (Span of Control) עלה מ-8.1 (2013) ל-12.1 (2025).
  • פיצול המשטר / הון סוכנים (Farach, 2026): משטר תשתית כללית (שוויוני) מול משטר משלימות עילית ("סופרסטאר", ריכוזיות קיצונית).

המטבע החדש: כלכלת הקשב (Attention Economy)

  • כשמידע זמין וזול, המשאב הנדיר הוא תשומת הלב (Simon 1971; Davenport & Beck).
  • אקדמיה: ציטוטים · רשתות (TikTok/YouTube): עוקבים/לייקים · בידור (Netflix): זמן צפייה.

תפקיד המנהל בעידן ה-AI (3 אתגרי-על)

  1. יצירת משמעות ושייכות — כשהכסף אינו המניע היחיד.
  2. מניעת התבדרות — עובד עם סוכן אינסופי מסתעף; המנהל "מכוון הווקטור הארגוני".
  3. סגירת פערים ושימוש דינמי — Noy & Zhang: פעם נדרשו 5 יחידות מתמטיקה; היום כולם יכולים.

תרחיש גיאופוליטי (המחשה, לא נבואה)

  • פרדוקס פיזי: כלכלת אינסוף דיגיטלי נשענת על נדירות פיזית — אנרגיה (חשמל) ושבבים.
  • מגן הסיליקון (Silicon Shield): תלות עולמית ב-TSMC (90%+ מהשבבים המתקדמים) = ביטוח לטייואן.
  • תלות גומלין נשקית (Weaponized Interdependence, Farrell & Newman): מעצמות משתמשות בצווארי בקבוק של שרשראות הערך ככלי כפייה.
  • לאומנות טכנולוגית: חוק השבבים האמריקאי (CHIPS Act), בקרת ייצוא ASML/TSMC.

המלצות מעשיות

  • מיפוי עצמי של רכיבי עבודה (טכני-שגרתי → יוחלף ב-AI).
  • כלל הזהב: צא מאזור הנוחות, למד נושא חדש כל יום — הגמישות המחשבתית = תעודת הביטוח היחידה.
  • TikTok ככלי לימוד — סרטונים מזוקקים 1–3 דק' (עם סינון חזק).

🟦 הרצאה 05 — Vibe Coding בפייתון

נקודות ליבה

  • Vibe Coding = כתיבת קוד בשפה חופשית (טבעית), בלי לדעת תכנות — ה-AI מייצר את קוד הפייתון.
  • המשל: Python הוא המנוע של הרכב — בלעדיו הקוד לא ירוץ.

⭐ ארבעת השלבים (סדר קריטי!)

  1. הגדרת המשימה בצ'אט (שפה חופשית + "תסביר איך להריץ")
  2. העתקת הקוד (Ctrl+C)
  3. שמירה ב-Notepad++ כקובץ .py (חובה סיומת, בלי רווחים)
  4. הרצה ב-PowerShell: python <filename>.py

כלים ופקודות

  • בדיקת פייתון: python --version · הרצה: python file.py · אימות קובץ: dir/ls
  • תרגיל Hello World: print("Hello") · פרויקט מרכזי: שעון אנלוגי בספרייה הגרפית Turtle.
  • תיקיות פרויקט: C:\201 (קבוצה א') / C:\101 (קבוצה ב').

שני מסלולי עבודה

  1. דרך הדפדפן: צ'אט → Notepad++ → PowerShell (שלוש תוכנות).
  2. דרך הטרמינל (Claude Code/Codex): הכל במקום אחד — יתרון מרכזי.
    - לטרמינל: כתוב בעברית → תרגם ב-Google Translate לאנגלית → הדבק.

פתרון בעיות

  • טקסט הפוך → העתק לצ'אט ובקש תיקון.
  • "כעסו על ה-AI" — הפנו ביקורת, בקשו תיקון, בצעדים קטנים ("מרוב עצים לא רואים את היער").

🟦 הרצאה 06 — שרשרת אספקה מבוססת AI (תאוריה)

נקודות ליבה

  • שימוש ב-AI = הכרח, לא פריבילגיה ("פורמולה 1 מול סוס ועגלה").
  • כלים מסורתיים (Excel, ERP) — איטיים ומאוחרים מדי. "מכפיל 16": מ-100 שורות קוד ל-10,000.

⭐ כלכלת AI חיובית מול שלילית

שלילית חיובית
מהות AI סגור, ללא בקרה תמיד אדם בלולאה (Man in the Loop)
האדם מוצא מהמשוואה מתווך, מבקר, אחראי
- "אם אתה לא שם — אתה לא קיים". לעולם אל תיקח תוצר כמו שהוא ותשלח.
- ה-AI הוא כלי עבודה, לא תחליף (כמו טרקטור לחקלאי). את תחום המומחיות שלך — אל תמסור לצ'אט (הגרפיקאית / עורך הדין עם התקדימים המומצאים).

כיצד עובד LLM

  • ה-LLM הוא "מוח" — יודע סטטיסטיקה, לא חשבון. מחזיר את מה שהופיע הכי הרבה ("דוד מלך..." → "ישראל").
  • הזיות (Hallucinations) — המצאת מידע לא נכון. הטל ספק — נראה ~90% אמין.

⭐ Training מול Inference

אימון (Training) הסקה (Inference)
היצרן מריץ על כל האינטרנט, לומד תבניות המשתמש מכוון מודל מאומן לתשובה (פרומפט)
- לכל מודל תאריך תוקף; מידע עדכני דורש מודל מאומן + חיפוש באינטרנט.

⭐ Chat מול Agent

שיחה (Chat) סוכן (Agent)
שאלה-תשובה מול ה"מוח" מקבל מטרה, מפרק לתת-משימות, מפעיל כלים (Tools) ומבצע
- הסוכן חותר למטרה אוטונומית; חייב אדם בלולאה (אנלוגיית המטווח — 3 כדורים ובדיקה).

⭐ הנדסת פרומפטים — 4 כללים

  1. הגדרת תפקיד ("התנהג כמומחה ללוגיסטיקה" / כאיש מקצוע ידוע).
  2. שפה חופשית + תבנית JSON (דיוק ותקשורת בין סוכנים — דוגמת הסלון והספה עם Nano Banana).
  3. מתן דוגמה (הובלה בשביל הנכון ביער).
  4. בקשת ביקורתיות — חפש "חריגות" ולא "התאמה".
    - ועדת מומחים — הקם ועדה וירטואלית, שחק "פינג-פונג" בין צ'אטים.

פרטיות והרצה מקומית

  • On-Prem / Ollama — הרצת מודל מקומית ("נגן" ל-LLM); מורידים מ-Hugging Face. יתרון: אין עלות טוקנים, מידע נשאר בבית; חיסרון: יקר (~10–20 אלף ש"ח / שרת $50K) + System Admin. מרוויחה: Nvidia.

🟦 הרצאה 07 — תרגול מעשי בשרשרת אספקה (בדפדפן)

נקודות ליבה

  • עבודה מתוך הדפדפן (לא טרמינל): מעלים קבצים, שואלים, מקבלים סיכום. אין צורך בקוד.
  • ⭐ סשן חדש לכל משימה (New Chat) — כל משימה = מקרה נפרד; ערבוב = "רעש" ("בשר בחלב").
  • בחירת קבצים רלוונטיים — בכוונה יש יותר קבצים מהנדרש; צירוף לא-רלוונטי מבלבל את המודל.
  • ⭐ אל תצרף את שקף המצגת למודל — הוא לרקע הלומד בלבד; המודל מקבל רק מסמכי המקרה.

שלושה רובדי למידה

  1. טכני (העתק-הדבק-Enter) 2. אימות וביקורת ("זה לא נכון, תתקן") 3. פרסונות (Act as).

⭐ אימות ואחריות מקצועית

אתם חתומים על התשובה. המודל מאיץ אך לא מחליף שיקול דעת. אל תניחו שהמודל צודק.

דוגמה מרכזית — עיכוב משלוח

  • מסמך מפתח: מדיניות הטיפול בעיכובים (Delay Response Policy).
  • שתי רמות: השלכה מקומית מול אפקט שרשרת (משלוחים נוספים "בקנה").
  • תוצר: סיכום 3 משפטים, SKUs בסיכון, 3 חלופות, טבלת החלטה (פעולה/עלות/שירות/סיכון/אישור).

מונחים

Incoterms (תנאי סחר בינ"ל) · SLA · רב-מודלי (Multimodal) · ETA · ROI · Share Link (הגשה בפרטי בצ'אט Zoom).

⭐ הרצאה 08 — Skills וחלון הקשר (הכי טכנית)

⭐ ארבעת מרכיבי הסוכן (Weng, 2023)

מרכיב תפקיד מונח אקדמי
LLM קבלת החלטות, תכנון ליבת היסק (Brain)
חלון הקשר (Context Window) זיכרון עבודה זיכרון קצר-טווח (Working Memory)
כלים (Tools) ביצוע פעולות API חיצוני
מאגר ידע (RAG) מסמכים ונהלים זיכרון חיצוני ארוך-טווח
> RAG אינו רכיב קוגניטיבי נפרד — הוא יישום של זיכרון ארוך-טווח + כלי אחזור (Retriever).

טוקנים וחלון הקשר

  • טוקן ≈ 0.75 מילה באנגלית (מילה ≈ 1.3 טוקן). חלון: 200K → מיליון טוקנים.
  • ⭐ "אובדן באמצע" (Lost in the Middle, Liu et al. 2024): דיוק גבוה בקצוות (Primacy + Recency), נמוך במרכז — עקומת U. מקם מידע קריטי בקצוות.
  • ⭐ סיבוכיות O(N²) — מנגנון הקשב העצמי (Self-Attention) ב-Transformer ריבועי ב-N (מס' טוקנים). שיחות ארוכות → יקרות ואיטיות → "ריקבון הקשר" (Context Rot).

⭐ שלוש אסטרטגיות ניהול + פקודות

פקודה פעולה
/clear מאפס את החלון, סשן חדש (מאבד זיכרון עבודה)
/compact דוחס לתמצית באותו סשן (Lossy — מאבד ניואנסים)
/resume משחזר שיחה קודמת
/rename נותן שם לשיחה
> סגירת המחשב אינה מאפסת את הסשן.

⭐ מס הטוקנים (The Token Tax)

  • פוריות (Fertility) F = Tokens/Words: אנגלית ≈ 1.3, עברית ≈ 3.25 (פי ~2.5). הסיבה: אלגוריתם BPE מאומן על אנגלית → מפרק עברית ל"רסיסים".
  • ארבעה מיסים: פיננסי (פי 2.5) · חישובי (O(N²)) · קיבולת קוגניטיבית (חלון מתמלא מהר) · דיוק (עולה הזיות).
  • המלצה: לעבוד באנגלית כקלט, לתרגם לעברית רק בפלט.

⭐ GraphRAG (Edge et al. 2024, Microsoft)

  • ייצוג ידע כגרף (צמתים/קשתות) + גילוי קהילות (Leiden/k-core) + סיכום היררכי.
  • RAG וקטורי נכשל בשאילתות גלובליות (Flat chunks); GraphRAG חוסך עד 90% טוקנים.

תזמור סוכנים

  • Flat Mesh (מבוזר-שטוח) — כשלים: Coordination Overhead, Context Fragmentation ("טלפון שבור"), Review Thrashing.
  • תזמור היררכי (OrgAgent): שכבות משילות (CEO Agent) / ביצוע (Coder) / תאימות (CCO Agent).

⭐ תקן SKILL.md

  • מיומנות (Skill) = תיקייה עם SKILL.md, מקנה תפקיד ומומחיות (שכפול הצלחות, לא "לוח חלק"/Tabula Rasa).
  • מבנה דו-שכבתי: Frontmatter (YAML) — שדה Description = מנגנון הניתוב האוטונומי; + גוף Markdown (הוראות + דוגמאות Few-shot).
  • גילוי הדרגתי (Progressive Disclosure): רמה 1 מטא-נתונים (תמיד) → רמה 2 הנחיות (בהפעלה) → רמה 3 משאבים (בביצוע).

סוכן מול מיומנות מול פקודה

אנלוגיה
סוכן (Agent) המוח (Brain)
מיומנות (Skill) הידיים (Hands)
פקודה (Command) קיצור מקלדת (/clear)

פרדוקס אוטומציה–אוגמנטציה (Raisch & Krakowski 2021)

  • אוטומציה (החלפת האדם) מול אוגמנטציה (שיתוף אדם–מכונה, "טייס משנה"/Copilot).
  • אוטומציה מלאה → שחיקת מומחיות (Skill Degradation). המסר: "מינוף ולא תחליף".

🟦 הרצאה 10 — מולטימדיה עם סוכני AI

נקודות ליבה

  • מחסום הכלי המורכב: פער בין כוונה ("חבר וידאו לקצב") לביצוע טכני (פקודת FFmpeg). הפתרון: עטיפת הכלי במיומנות בשפה טבעית.
  • ⭐ וידאו = מיכל (Container) — לרוב MP4 (ISO/IEC 14496-14). בתוכו ערוצים (Tracks): תמונות, שמע, כתוביות. כל ערוץ ניתן להכפלה (רב-לשוני).
  • סנכרון: חותם זמן (Timestamp) מלכד את הערוצים; עריכה = הזזת תכנים על ציר הזמן.

⭐ מודל "השמע מוביל" (Audio-leads)

  • בקליפ, ערוץ השמע קובע את הקצב, השאר מיישרים אליו ("כמו חיילים לתוף"). במצגת מוקלטת — התמונות מובילות.
  • ~90% מהקטעים נלווה שמע → השתקה לפני הרכבה.
  • מקצב 4/4 = 4 רבעים לבית מקצב (Bar). החלפת תמונה בכל בית = "וידאו ארט"; בכל ביט = פי 4 מהיר.
  • זיהוי ביטים אוטומטי: librosa (beat_track → tempo ב-BPM + נקודות חיתוך). רץ מקומית — לא מבזבז טוקנים.

FFmpeg והסוכן

  • FFmpeg = מנוע עריכה טקסטואלי (חיתוך/הדבקה/השתקה). המיומנות (תוכנית Python) מתרגמת שפה טבעית לפקודת FFmpeg ומסתירה אותה. החלפת מנוע → עדכון המיומנות בלבד.
  • ⭐ סוכן CLI מקומי מול צ'אט דפדפן: המקומי ניגש לקבצים ומריץ FFmpeg; הדפדפן יכול לכתוב פקודה אך לא להריצה.
  • ⭐ כלכלת טוקנים: המודל "מנצח" בלבד (פקודות קצרות) ולא מייצר את המדיה הכבדה → זול. עלות הנמקה ריבועית באורך הרצף.

צינור ההפקה (8 שלבים)

Lyrics (מנוקד! ≤60 שנ') → Style JSON → Suno.AI → הורדת MP3 → הוספת תמונות מושתקות → פתיחת CLI בתיקייה → פרומפט "השמע מוביל, FFmpeg" → תוצר .mp4.
- היגיינת פרויקט: הכל בתיקייה אחת (C:/101). פרט אישי מדויק > ברכה כללית (שיר המדחס).

חזון: Agentic OS

  • מעבר ממערכת ממוקדת-יישומים (App-centric) לממוקדת-כוונה (Intent-based) — סוכן יחיד מתזמר כלים.
  • עטיפת כלים (Tool Wrapping): Blender, LaTeX/MiKTeX, CAD/OpenSCAD, R.
  • MCP (Model Context Protocol): תקן פתוח לחיבור סוכנים לכלים ומקורות — "חותך" את תלות ה-GUI.

📝 מאגר שאלות תרגול (מדגם)

יש 80 שאלות תרגול מלאות (8 לכל הרצאה) — הנה מדגם. בקש ממני עוד/מבחן מלא בכל עת.

1 (L01). תמונת 1000×1000 פיקסלים מיוצגת כ...? → וקטור במיליון מימדים (נקודה במרחב מיליון-ממדי).

2 (L04). לפי מודל השוק מבוסס-סוכנים, לאן שואף מחיר מוצרי מידע? → P → MC → 0 (העלות השולית האפסית).

3 (L06). איזה פורמט מתאים לשיחה בין שני סוכנים? → JSON.

4 (L06). ההבדל בין Chat ל-Agent? → סוכן מקבל מטרה, מפרק לתת-משימות ומבצע פעולות בעזרת כלים; שיחה = שאלה-תשובה בלבד.

5 (L08). סיבוכיות מנגנון הקשב? → O(N²) ריבועית.

6 (L08). פוריות טוקניזציה עברית מול אנגלית? → ~3.25 מול ~1.3 (פי ~2.5), בגלל BPE.

7 (L08). ההבדל בין /clear ל-/compact? → /clear מאפס סשן חדש; /compact דוחס תמצית באותו סשן (Lossy).

8 (L09). סדר מחזור הפיתוח? → PRD → Plan → To-Do.

9 (L09). ההבדל בין Push ל-Pull? → Push מעלה למחשב→ענן; Pull מוריד מענן→מחשב.
