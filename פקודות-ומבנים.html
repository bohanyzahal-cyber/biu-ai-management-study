skill.md — חמשת החלקים

# Supply Chain Analyst Skill
## Role
You are a supply chain analyst responsible for
inventory monitoring and restocking decisions.
## Inputs
- Inventory CSV files
- Stock levels and reorder thresholds
## Tools
- inventory_tool.py (Python analysis tool)
## Behavior
1. Load inventory data
2. Identify items where stock < reorder_level
3. Rank items by urgency (lowest stock first)
4. Recommend restocking priorities
## Rules
- Always use exact numeric comparisons
- Prefer tool usage for calculations
חלקתפקידו
Roleהפרסונה — מי הסוכן ומה תחום אחריותו
Inputsאילו נתונים הוא מקבל
Toolsאילו כלים (סקריפטים) עומדים לרשותו
Behaviorסדר הפעולות — הלוגיקה עצמה
Rulesאילוצים קשיחים (למשל: תמיד להעדיף כלי על חישוב עצמי)

ה-tool בפייתון (inventory_tool.py)

import pandas as pd

def analyze_inventory(path):
    df = pd.read_csv(path)
    df["need_reorder"] = df["stock"] < df["reorder_level"]
    low = df[df["need_reorder"] == True]
    return {
      "total_items": len(df),
      "low_stock_count": len(low),
      "critical_items": low.sort_values("stock")[
          ["item_name","stock","reorder_level"]
      ].to_dict(orient="records")
    }
