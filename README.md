## שימוש באתר התרגול

פתחו את `אתר-תרגול.html` בכל דפדפן — אין צורך בהתקנה או שרת. בוחרים נושא (או סימולציית מבחן), עונים, ומקבלים משוב והסבר מיד. סדר התשובות מתערבב בכל ניסיון. הציונים הטובים ביותר נשמרים מקומית בדפדפן.

## ⚠ על 180 שאלות המבחן לדוגמה

השאלות נדגמו ישירות ממאגר הבחינה ופורסמו ב-Moodle ב-18.08.2026. **המרצה לא פרסם מחוון** — סקירת התשובות בבוחן מושבתת, והוא הנחה במפורש לקבוע את התשובות בעזרת מודל שפה.

לכן התשובות בנושא הזה **אינן רשמיות**: הן נקבעו בניתוח מול חומרי הקורס. **כל 29 השאלות שסומנו בביטחון בינוני אומתו אחת-אחת מול סיכומי המרצה** (18.08): 26 אושרו — רובן מילולית מן המקור — ו-**3 תוקנו** בעקבות האימות: מס הסוכנים (Guerreiro, Rebelo & Teles — התנאי הוא דור עובדים שאינו יכול להסב), שיחות הסלולר (תקדים לקריסת מחיר), ועלות השימוש (אזורי הקבע מחויבים בכל תור). הסבר הנושא בכל שאלה כזו מסומן "(אומת מול סיכום המרצה)". 50 שאלות בוחן החזרה נשארו בנושא נפרד ותשובותיהן כן רשמיות.

## עדכון החוברת

`חוברת-לבחינה.html` נבנית אוטומטית מקבצי המקור (דף העזר, המילון, הפקודות, המדריך ובנק השאלות).
אחרי עדכון של אחד מהם מריצים:

```bash
python build_booklet.py
```

התבנית (עיצוב, מנוע העימוד וסעיף האסטרטגיה) נמצאת ב-`booklet_template.html`.
