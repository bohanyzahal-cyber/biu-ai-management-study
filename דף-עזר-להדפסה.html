01 · AI כווקטורים ולמידת מכונה

  • ייצוג וקטורי: כל תכונה=ממד. תמונה 1000×1000=וקטור ב-מיליון מימדים. דומים=קרובים. "למידה"=מציאת הגבול המפריד.
  • 4 סוגי ML: רגרסיה=ערך רציף (מחיר/ביקוש) · סיווג=קטגוריות בדידות · חריגות=נדיר (הונאה) · חיזוק (RL)=תגמול (שחמט).
  • Overfitting=למד "בעל פה". Feature=תכונה נמדדת. Deep Learning=רשת נוירונים.
  • סיכון LLM ענן: מידע "יוצא החוצה" (man-in-the-middle).

03 · טרמינל ו-Codex

  • Codex=CLI של OpenAI. סוכן=טקסט בלבד (לא עכבר). פרויקט=תיקייה.
  • mkdir=תיקייה · python file.py=הרצה · Windows מפריד=\
  • סדר התקנה: PowerShell→Node/npm→הרשאה→Codex→התחברות. אחרי Node → לסגור/לפתוח טרמינל.
  • npm i -g @openai/codex · codex login=OAuth 2.0.
  • exit בתוך Codex=יוצא ונשאר בטרמינל · exit בטרמינל=סוגר (שתיהן exit!). Sandbox=הרצה מבודדת (מונע Prompt Injection). Set-ExecutionPolicy RemoteSigned=הרשאת סקריפטים.

04 · כלכלת ה-AI

  • מחיר מידע: P→MC→0 (עלות שולית אפסית). המטבע החדש=הקשב (Attention).
  • Jagged Frontier=גבול יכולת לא-אחיד. Noy&Zhang: −40% זמן, +18% איכות.
  • דחיסת פריון=החלשים נהנים הכי הרבה. פתרון סגל=מס על סוכני AI.
  • מגן הסיליקון=TSMC (90%+ שבבים). ההשטחה: טווח שליטה 8.1→12.1.
  • סוציאליזם=כשל אפיסטמי (אין חישוב ללא שוק). תלות נשקית=צווארי בקבוק ככפייה.
  • גישת המשימות: מקצוע=אוסף משימות. 3 אפקטים: החלפה·פריון·השבה. סיכון=רכיב טכני מול אנושי (10×25%→~3). פיצול משטר: תשתית כללית↔משלימות עילית (סופרסטאר). Digital Gosplan=אזהרת ריכוזיות (הררי).

  • פייתון=המנוע. שעון=ספריית Turtle. קובץ=.py בלי רווחים. טעה→"כועסים עליו".

06 · שרשרת אספקה (תאוריה)

  • שיחה=שאלה-תשובה · סוכן=מטרה→תת-משימות→כלים. אין לסמוך על חשבון LLM. הזיה=המצאת "הכי הגיוני".
  • 2 שלבי מודל: אימון+הסקה. תאריך תוקף=היום שאומן עד אליו. כלכלה חיובית=אדם בלולאה.
  • Claude=אלוף קוד · Nano Banana=תמונות · Ollama=מקומי (אין טוקנים).
  • 4 כללי פרומפט: תפקיד · JSON · דוגמה · ביקורתיות ("חריגות"). ועדת מומחים=גלם מומחים→הנחיות→מענה→ביקורת (פינג-פונג). מודלים: Grok=לוגיקה/מסמכים · Gemini=מולטימדיה · Perplexity=חיפוש · Manus=מצגות. AI=כלי לא תחליף.

07 · תרגול שרשרת אספקה

  • סשן חדש לכל משימה. קבצים מיותרים→שיקול דעת. מסמך מפתח=מדיניות עיכובים.
  • אפקט השרשרת=עיכוב פוגע במשלוחים "בקנה". אחריות+אימות=על הלומד. שקף=רקע בלבד (לא לצרף).
  • Incoterms=תנאי סחר בינ"ל. הגשה=פרטי בצ'אט Zoom. 3 דבורי למידה: טכני→אימות/ביקורת→פרסונה. Act as="התנהג כמומחה". טבלת החלטה: פעולה·עלות·השפעה·סיכון·אישור.

08 · Skills וחלון הקשר

  • קשב=O(N²). Lost in Middle=דיוק בקצוות (Primacy+Recency).
  • טוקנים: אנגלית ≈1.3 / עברית ≈3.25 (×2.5, בגלל BPE). מס הטוקנים=4 (פיננסי/חישובי/קיבולת/דיוק).
  • /clear=מאפס · /compact=דוחס. 4 מרכיבי סוכן: LLM·חלון הקשר·כלים·RAG.
  • GraphRAG=חוסך עד 90% טוקנים. מומלץ אוגמנטציה (טייס משנה).
  • Progressive Disclosure=3 רמות (מטא→הנחיות→משאבים). חלון: 200K→מיליון.
  • סוכן·מיומנות·פקודה=מוח·ידיים·קיצור. SKILL.md=תיקייה (YAML+Markdown); Description=מנגנון ניתוב. תזמור היררכי 3 שכבות: ממשל·ביצוע·תאימות (מול כשלי "רשת שטוחה"). פקודות: /resume,/rename. תשלום: מנוי↔API Key. "שפר את המיומנות, לא התוצר".

09 · Git, GitHub, Gmail API

  • Client=תקשורת · Token=הרשאות. לא מילת-מפתח בודדת (Rule-based)→זיהוי כוונה.
  • 4 תפקידי OAuth: Resource Owner·Client·Auth Server·Resource Server.
  • 144 commits=מקצועי · אחד=לא. מחזור=PRD→Plan→To-Do. README=מה+איך מריצים.
  • Push=מחשב→ענן · Pull=ענן→מחשב. Git: Torvalds, 2005.
  • Moat=VRIN: Valuable·Rare·Inimitable·Non-substitutable. דילול=~3–5%.
  • Branch=ענף מקביל · Merge=איחוד ל-main. Commit=מקומי · Push=לענן (דיסק מתקלקל→רק push שרד). CI/CD=בדיקות אוטומטיות לילה. מימון: Angel→Seed→דילול.

10 · מולטימדיה

  • .mp4=מיכל (Container). "השמע מוביל"=ערוץ שמע קובע קצב. הפקה "לא שותה טוקנים"=רק מתזמר.
  • CLI מקומי מריץ FFmpeg; דפדפן רק כותב. מיומנות עוטפת FFmpeg=Python→פקודה. ~90% קטעים להשתיק.
  • MCP=תקן פתוח לכלים חיצוניים. Agentic OS=מעבר לממוקד-כוונה.
  • מיכל=ערוצים (וידאו·שמע·כתוביות, ניתנים להכפלה). סנכרון timestamp (הזזת שמע→שוברת). ניקוי=השתקת גלם לפני הרכבה. Suno.AI=Lyrics+Style ([chorus]=הנחיה). ניקוד=להגייה עברית. סגנון ב-JSON.

11 · מצגות HTML בסוכן AI

  • מחסום הכלי→הופך: מתארים כוונה בשפה טבעית והסוכן בונה.
  • Full-Stack=Front-end (רואים) + Back-end (שרת). מבחן ניתוק הכבל: נעצר=שרת · ממשיך=מקומי. מצגת HTML=מקומי.
  • מצגת=אתר מקומי. דפדפן=נגן. שקופית=דף HTML. index.html=דף נחיתה. שיתוף=כל התיקייה.
  • Pipeline: תסריט(צ'אט)→AI.txt→סוכן CLI מייצר HTML→לחיצה כפולה index.html. תסריט ולא שקופיות. הדרגתי.
  • סוגים: אובייקטים (טכני/קר) · תמונות (חגיגי). JSON=גשר לשאיבת סגנון (כמו Suno).
  • 3 שכבות: HTML(מבנה)·CSS(עיצוב)·JS(התנהגות)=הפרדת דאגות. .js≠Java. BiDi=כיווניות (UAX #9).
  • פס-קול=FFmpeg (חיבור L10). תיאום רב-סוכני: תסריטאי+מקודד→שליט/חוזר. מגבלות: הזיות(אדם בלולאה)·נגישות(WCAG)·אבטחה. חלופות: reveal.js/Marp.
